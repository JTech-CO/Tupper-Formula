# 연구 방향: 신규성 주장보다 명시적인 구성

## 현재 버전의 기여

좌표 계약, 서로 다른 정확한 산술 경로, 수식 마스크 구성기, 재현 예제, 이중 언어 설명, 상호작용 실험실을 결합했다. 교육·재현 관점의 기여이며 수학적 항등식이나 생성한 k가 문헌에 없었던 새로운 결과임을 입증하지 않는다.

## 실험 A — 조판을 통제 입력으로 보기

H·수식 형태를 고정하고 임계값·해상도·글꼴 중 한 변수를 바꾼다. 이진 불일치·잉크 칸 수·너비·k 자릿수·기호 가독성을 측정한다. 정수가 작아졌다고 더 좋은 자기참조 공식은 아니다. 정확한 마스크를 보존해 렌더러 차이와 복호화 오류를 구분한다.

현재 렌더러는 내부 수학 글꼴을 고정하고 H·임계값·형태를 제공한다. 글꼴 스윕은 출처를 기록한 렌더러 개정이 필요하며 현재 CLI 옵션이 아니다.

## 실험 B — 표현 언어 제한

길이 최적화 전에 상수·연산·재귀·합·기본 함수·글리프 렌더러의 문법을 정한다. 보조함수 정의와 상수를 포함한 전체 표현을 센다. 복호화기를 길게 만들어 데이터 정수를 줄이는 것은 상충관계이지 자동 압축이 아니다.

유한 열거기·제약 해결기로 짧은 동치 복호화기를 탐색할 수 있지만 현재 버전에 탐색 엔진은 없다. 정확한 탐색 범위·증명·검사기가 필요하며 제한된 탐색의 실패는 범위 밖 부재를 증명하지 않는다.

## 실험 C — 강한 자기완결적 구성

합의한 언어 아래 식 본문·숫자 출력기를 모두 구현하고 필요한 상수·보조함수 정의도 보이는 식에 넣는 확장이 의미 있다. `N = 2^L A + D`는 본문 A와 숫자 사전 D를 나누는 개념 설계이며 완성된 보편 해법이 아니다.

십진수 r번째 자리는 `floor(N/10^r) mod 10`으로 읽지만 종료·배치·인용과 치환·완전한 자기 기술은 여전히 구성해야 한다. 의미론적 재귀 정리를 인용한다고 수치 반복 치환이 수렴하지 않는다. 최초 사례를 주장하기 전에 [문헌](LITERATURE-KR.md)의 원 구성을 비교한다.

## 실험 D — 표본 그림이 아닌 정확한 집합

픽셀 부등식은 칸 내부 상수성을 먼저 보이면 칸당 내부 표본 하나로 검사할 수 있다. 곡선은 유한 격자의 값이 같아도 평면 영역의 동일성을 일반적으로 증명하지 못한다. 베지어·글리프 확장은 경계 약속과 내부·외부 판정의 정당화가 필요하다. 집합 동일성, 경계를 제외한 동일성, 래스터 동일성, 시각적 유사성을 구분한다.

## 결과 수용 기준

연구 변경은 질문·기준선·가정·구현/제안 구분·외부 정보·재현 환경·정확한 산출물·부정 결과·시험 한계를 명시한다. 신규성에는 문헌 비교가 필요하다. 생성기 실행 성공만으로 뒷받침되는 것은 명시한 구성 산출물의 범위이다.
