# 한계와 비목표

## 과학적 범위

구현한 자기 이미지는 **외부 k**로 선택한다. k의 모든 숫자를 같은 그래프에 넣지 않으며 제한 없는 자기 기술을 해결하지 않는다. SVG는 정사각형 칸이고 Trávník의 매끄러운 곡선이 아니다. C진수 패킹은 완전한 n변수 일반화 그래프 시스템이 아니다. 자동 정리 증명기·신규성 판별기·일반 최단 수식 해결기·신경망 이미지 인식기는 포함하지 않는다.

정확성은 저장된 이진 마스크와 지정한 반열린 영역에 대한 것이다. 임의 사진의 무손실 복원, 수식의 의미 이해, 그림 속 문장의 진리, 무한한 전체 그래프와 유한 조판 표현의 동일성을 뜻하지 않는다. 더 큰 k에서도 같은 그림이 반복될 수 있다.

## 수치·구현 제한

Python·JavaScript의 자원 정책이 다르므로 모든 Python 산출물을 브라우저에서 읽을 수 있는 것은 아니다. 거대한 십진수 변환·정확한 분수 계산은 비싸질 수 있다. 제한은 의도적이며 신뢰할 수 없는 파일 처리를 위해 무작정 없애지 않는다. Python은 음이 아닌 정수·Fraction 좌표, UI는 이산 칸을 사용한다. 543자리 k 부근의 절대 좌표를 부동소수점으로 취급하는 것은 적절하지 않다.

인코딩·복호화가 같은 결함을 공유할 수 있다. 알려진 예제·비대칭 데이터·유리수 추출·언어 간 검사가 이를 줄이지만 완전히 제거하지는 않는다. JSON Schema만으로 `k=HN`·해시를 증명할 수 없다. 해시 일치는 출처·과학적 타당성·충돌 불가능성을 증명하지 않는다.

## 렌더링·표현

Mathtext와 이진화는 소프트웨어·글꼴·플랫폼에 따라 다른 이진 목표를 만들 수 있다. 같은 LaTeX가 같은 픽셀을 보장하지 않는다. 글꼴 파일은 동봉하지 않는다. 네이티브 MathML은 브라우저마다 다를 수 있으며 스크린리더·전체 WCAG 적합성을 인증하지 않는다. 한국어 본문은 클라이언트 전환이며 별도로 완전히 사전 렌더링된 검색 경로가 아니다.

클립보드 권한·Web Crypto 보안 컨텍스트·로컬 파일 제한은 실제 플랫폼 제약이다. 오류·대체 입력을 제공하지만 정책을 재정의하지 않는다. 브라우저 테스트 대역은 요청 동작을 확인할 뿐 운영체제 클립보드 접근을 입증하지 않는다. 소셜 카드 수집·Pages 실제 배포는 공개 후 시험한다.

## 운영 범위

연구 소프트웨어이며 적대적 파일을 격리 분석하는 서비스가 아니다. 출처 불명 이미지는 제한된 환경에서 처리하고 선택적 이미지 라이브러리를 최신 보안 상태로 유지한다. 서버 계정·클라우드 저장·공개 업로드 엔드포인트는 없다. ZIP이 GitHub 저장소를 생성하지 않는다. 유지보수 일정·서비스 수준·향후 의존성 가용성을 보장하지 않는다.

출처를 표시하지만 논문을 전문 재배포하지 않는다. 제3자 구현을 재사용할 때는 해당 라이선스를 따른다. 프로젝트 MIT는 저장소 밖의 논문·저자 코드를 재라이선스하지 않는다.
