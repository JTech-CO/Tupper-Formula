00 Abstract

A compact inequality can draw an image of its own notation. The mechanism is not recognition: it is exact decoding of bits stored in an integer. The celebrated window is one member of a family containing every binary image of the same dimensions. The original paper presents it as a grid-enumeration example. [1]

This repository separates a proof, a browser experiment, and a Python construction pipeline. The experiment changes individual pixels and observes their effect on the integer. The Python program typesets a chosen equivalent predicate, constructs its offset, and verifies the resulting binary mask.

Scope of the result. A Tupper-type self-image still needs an external offset k and viewport. This implementation does not claim to construct a formula that prints its entire constant, prove a new theorem, or solve semantic self-reference.

01 From pixels to a predicate

Choose a width W and height H. Store rows from top to bottom in files, but count mathematical row j from the bottom. A filled cell has value 1. The column-major bit index is H*i + j; that convention is shared by the Python and JavaScript implementations.

Binary mask→Integer N→Offset k = HN→Exact graph

1. Encode the finite image

Assign one power of two to each cell. The image width is metadata: leading empty columns cannot be inferred from N alone.

Store an image in one integer
N=∑i=0W−1∑j=0H−1bi,j2Hi+j,k=HNN=\sum_{i=0}^{W-1}\sum_{j=0}^{H-1}b_{i,j}2^{Hi+j},\qquad k=HN
LaTeX source
N=\sum_{i=0}^{W-1}\sum_{j=0}^{H-1}b_{i,j}2^{Hi+j},\qquad k=HN

2. Read one binary digit

Divide by the corresponding power of two, discard the fractional part, then take the remainder modulo two. This is equivalent to (N >> (H*i + j)) & 1. Unlike floating-point evaluation at an enormous y, integer extraction preserves every bit.

Read one bit
bi,j=mod(⌊N2Hi+j⌋,2)b_{i,j}=\left\lfloor\frac{N}{2^{Hi+j}}\right\rfloor\bmod 2
LaTeX source
b_{i,j}=\left\lfloor\frac{N}{2^{Hi+j}}\right\rfloor\bmod 2

3. Recover both the data and index from coordinates

The following is a height-parameterized form of the decoder. Its value is either 0 or 1 in the nonnegative domain implemented here; the displayed inequality selects cells with value 1.

Generalized height H
BH(x,y)=⌊mod(⌊yH⌋2−H⌊x⌋−mod(⌊y⌋,H),2)⌋B_H(x,y)=\left\lfloor\operatorname{mod}\left(\left\lfloor\frac{y}{H}\right\rfloor2^{-H\lfloor x\rfloor-\operatorname{mod}(\lfloor y\rfloor,H)},2\right)\right\rfloor
LaTeX source
B_H(x,y)=\left\lfloor\operatorname{mod}\left(\left\lfloor\frac{y}{H}\right\rfloor2^{-H\lfloor x\rfloor-\operatorname{mod}(\lfloor y\rfloor,H)},2\right)\right\rfloor
The floor–mod identity
⌊mod(z,2)⌋=mod(⌊z⌋,2)\left\lfloor\operatorname{mod}(z,2)\right\rfloor=\lfloor z\rfloor\bmod 2
LaTeX source
\left\lfloor\operatorname{mod}(z,2)\right\rfloor=\lfloor z\rfloor\bmod 2

4. Prove equality throughout each cell

Use the half-open viewport 0 ≤ x < W, k ≤ y < k+H. Inside a cell, write the coordinates as follows. Since k = HN, the quotient floor(y/H) is N and floor(y) mod H is j.

Inside one unit cell
x=i+u,y=HN+j+v,0≤u,v<1x=i+u,\quad y=HN+j+v,\quad 0\le u,v<1
LaTeX source
x=i+u,\quad y=HN+j+v,\quad 0\le u,v<1

Applying the floor–mod identity gives the result below. Floors are constant inside each half-open cell, so this is equality of filled regions, not just agreement at sample points. It is a two-variable inequality, not a single-valued curve y=f(x).

Exact reconstruction
BH(x,y)=mod(⌊N2Hi+j⌋,2)=bi,jB_H(x,y)=\left\lfloor\frac{N}{2^{Hi+j}}\right\rfloor\bmod2=b_{i,j}
LaTeX source
B_H(x,y)=\left\lfloor\frac{N}{2^{Hi+j}}\right\rfloor\bmod2=b_{i,j}

Not unique

Higher bits beyond the W × H window are invisible. Adding a multiple of 2WH to N leaves that finite window unchanged.

Not free compression

There are 2WH masks and WH raw bits per mask. One large integer is one container, not a disappearance of information.

Another occurrence of the same window
kt=H(N+t2WH),t∈{0,1,2,…}k_t=H\left(N+t\,2^{WH}\right),\qquad t\in\{0,1,2,\ldots\}
LaTeX source
k_t=H\left(N+t\,2^{WH}\right),\qquad t\in\{0,1,2,\ldots\}

03 Beyond the original

“Self-reference” describes several distinct targets. A universal bitmap decoder is a useful starting point, but a self-contained graph must account for its constants, auxiliary definitions, typography, and entire stated domain.

What is reproduced, and what is actually implemented?
ConstructionDistinctionIn this repository
Tupper-type self-imageA selected window depicts the decoder; k is external.Implemented
Self-contained self-graphThe complete expression, including its constants, is drawn.Literature and design notes
Program quineA program outputs its own source.Conceptual comparison only
Logical self-referenceA sentence refers to its own formal properties.Not a pixel-encoding claim

Trávník’s bitmap construction includes the digits of its constant; his later version uses Bézier-defined glyph regions. His notes also credit Tupper’s later self-contained examples, identified there as 2007 files. That directory was not directly retrievable during this repository’s source check, so it is a credited lead, not a reproduced implementation. [2] [3]

Somu and Mishra extend the representation problem to multiple colors and dimensions. The separate radix.py module here demonstrates elementary base-C packing; it is not an implementation of their particular family of formulas. [4]

Read a base-C palette index
ci,j=mod(⌊NCCHi+j⌋,C)c_{i,j}=\left\lfloor\frac{N_C}{C^{Hi+j}}\right\rfloor\bmod C
LaTeX source
c_{i,j}=\left\lfloor\frac{N_C}{C^{Hi+j}}\right\rfloor\bmod C

A stronger, explicitly defined target

Fix the allowed expression language and a glyph renderer. Let Gr(s) be the graph of expression s, and Gl(s) its typeset shape. Alexander formalizes self-graphing using such distinctions and gives existence results under suitable expressiveness assumptions; this is not a promise of a short elementary expression. [5]

The stronger target
Gr(s)=Gl(s)\operatorname{Gr}(s)=\operatorname{Gl}(s)
LaTeX source
\operatorname{Gr}(s)=\operatorname{Gl}(s)

One practical route separates a fixed formula body from a digit printer. Instead of storing every digit as a separate bitmap, a shared glyph dictionary draws each extracted decimal digit. This is the role of reuse in Trávník’s explanation. [11]

Read the digits of an embedded constant
dr=mod(⌊N10r⌋,10)d_r=\left\lfloor\frac{N}{10^r}\right\rfloor\bmod10
LaTeX source
d_r=\left\lfloor\frac{N}{10^r}\right\rfloor\bmod10

Computability-theoretic fixed points concern equivalent behavior, not necessarily equal program indices. Repeatedly rendering a formula, encoding it, and inserting the resulting number back into the formula is not a generally convergent algorithm. [5]

A behavioral fixed point
∃eφe=φf(e)(not necessarily e=f(e))\exists e\;\varphi_e=\varphi_{f(e)}\qquad\text{(not necessarily }e=f(e)\text{)}
LaTeX source
\exists e\;\varphi_e=\varphi_{f(e)}\qquad\text{(not necessarily }e=f(e)\text{)}

04 Construct a new self-image

The derive command is the research program, not a website generator. It specializes H inside an inequality, renders that exact notation at the same raster height, thresholds the image, constructs N and k, and writes a verifiable experiment bundle.

Terminal · Python 3.11+
python -m venv .venv
# Activate the virtual environment, then:
python -m pip install -e ".[render]"
tupper derive --height 32 --variant tupper -o output/my-formula
tupper verify output/my-formula/experiment.json --literal

Choose --variant bit for the equivalent quotient-based notation, or change H to construct another member of the family. These are systematic new examples of an existing mechanism, not automatically new mathematical discoveries. A thresholded font can change across renderer versions; the saved binary mask is the exact reproducibility boundary.

05 Verification is part of the method

A source image that resembles the output is not sufficient evidence. This repository checks canonical dimensions, integer strings, the offset identity, a content digest, and pixel equality. The literal verifier additionally evaluates the nested floor–mod expression at every exact rational cell midpoint.

658 exhaustive masks5,442 rational midpoints0 mismatches

These figures describe the included deterministic arithmetic run, not performance benchmarks or all possible inputs. The algebraic identity proves the general reconstruction result. Test reports record the environment actually used; unrun browser and Python versions are not claimed as verified.

What the result does not establish

It does not prove that the font is legible, that the encoded text is mathematically true, that a constant is minimal, or that the entire unbounded graph equals the displayed text. It also does not recover the original antialiased image from a one-bit mask.

Research questions worth asking

Fix a notation language and a total description-length metric before minimizing expressions. Distinguish glyph reuse from hiding data in a named helper. For stronger constructions, include every constant and auxiliary definition, specify boundaries, and check the whole claimed domain. A smaller k alone is not evidence of less total information.
